# Portfolio personale — Giovanni Del Gaudio

**Sito ufficiale:** https://www.giovannidelgaudio.it/

Questo repository pubblico contiene il portfolio professionale bilingue e le demo navigabili dei progetti. I sorgenti delle applicazioni proprietarie complete **non** sono distribuiti qui.

## Contenuti

- **Portfolio IT/EN:** presentazione professionale, formazione, progetti e competenze.
- **Demo tecniche:** FORMA AI, DriveGlass, LegacyBridge, Fit Zone, GestioneFarmacia, e-Wine, SignalScope, Meteo Bash 2D e prototipi UX.
- **Interfaccia:** navigazione responsive, tema chiaro/scuro, orologio italiano Europe/Rome e accessibilità di base.
- **Changelog:** aggiornamenti bilingue basati su modifiche realmente pubblicate.
- **SEO:** metadati, sitemap, JSON-LD e link canonici.

Le demo rappresentano aspetti dimostrativi dei prodotti: non equivalgono all'esecuzione dei rispettivi backend privati.

## Qualità e pubblicazione

GitHub Pages pubblica automaticamente il ramo `main` con i workflow in `.github/workflows/`. I controlli verificano la build, le versioni italiane e inglesi, i riferimenti agli asset locali e alcuni requisiti di accessibilità.

Le modifiche al sito devono essere proposte tramite Pull Request **in questo repository**, non nel vecchio `forma-ai`.

## Privacy e documenti

Le immagini delle certificazioni sono materiale documentale dell'autore. **Attenzione:** alcuni attestati integrali presenti in `assets/certificates/full/` possono includere codici identificativi e QR visibili. È opportuno limitare la distribuzione pubblica dei documenti completi, mantenendo eventualmente le sole anteprime e i link di verifica ufficiali. La loro pubblicazione non equivale a una verifica indipendente delle credenziali.

Non pubblicare password, token, dati sanitari, copie integrali di documenti d'identità, configurazioni locali o informazioni personali non necessarie al portfolio.
