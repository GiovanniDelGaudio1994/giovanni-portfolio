THE METHOD

Misurare. Capire. Condividere.

01 · DISCOVER

Inventory

Rileviamo CPU, RAM, BIOS e storage con sonde non invasive e report anonimizzati.

02 · VERIFY

Instruction set

Separiamo x64, POPCNT, SSE4.2 e i vincoli del sistema operativo dai semplici blocchi dell'installer.

03 · EXPERIMENT

Live systems

Test da USB, risultati ripetibili, nessuna modifica del disco interno durante la diagnostica iniziale.

Open core sotto AGPLv3. Nessuna ISO Windows, DLL Microsoft o patch di kernel distribuite.
