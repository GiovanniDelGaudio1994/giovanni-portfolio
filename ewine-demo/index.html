Lo ZIP originale contiene filtri Servlet per autenticazione/autorizzazione e un file FiltroBrowser.java relativo al controllo del browser/User-Agent.

Questa pagina mostra lo User-Agent soltanto come diagnostica. Non replica né sostituisce la sicurezza lato server delle Servlet.

La storia di e-Wine

e-Wine è un progetto universitario per la vendita online di vini, con catalogo, area cliente, gestione dei prodotti e organizzazione delle spedizioni. È stato presentato nell'ambito di Tecnologie per il Software Web e documentato anche in relazione all'Ingegneria del Software.

Architettura originale

Java · JSP · Servlet · Bootstrap 4 · MySQL · Apache Tomcat

Nel materiale originale sono presenti una struttura di navigazione distinta per ruolo, un modello E-R, diagrammi di flusso e schermate dell'applicazione.

Codice sorgente originale: privato. Questa demo è una ricostruzione indipendente con dati fittizi.
